# Divisor de conta

Uma calculadora para dividir a conta de um restaurante, incluindo gorjeta, feita com HTML, CSS e JavaScript puro.

## Funcionalidades

- Calcular gorjetas de diferentes porcentagens
- Dividir o total pelo número de pessoas
- Exibir o valor da conta, da gorjeta e por pessoa
- Validar os valores informados

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências.
